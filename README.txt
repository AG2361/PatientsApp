PatientsApp - консольное приложение "Пациенты"
================================================

ОПИСАНИЕ
--------
Консольное Java-приложение для работы с коллекцией медицинских пациентов.
Учебный проект по дисциплине "Специализированные инструменты прикладного
программирования" (базовый уровень).

Приложение позволяет:
  - добавлять пациентов вручную через консоль;
  - загружать пациентов из текстового файла;
  - фильтровать, преобразовывать и сортировать данные с помощью Stream API;
  - работать в цикле до выбора пункта "Выход".

ТРЕБОВАНИЯ
----------
  - Java 17 или выше (JDK);
  - IntelliJ IDEA (проект создан в версии 2026.2.3, подойдёт любая
    современная версия);
  - сторонние библиотеки не нужны.

ЗАПУСК
------
  1. Откройте папку проекта в IntelliJ IDEA (File -> Open).
  2. Убедитесь, что в File -> Project Structure -> Project выбран JDK 17+.
  3. Откройте файл src/app/Main.java.
  4. Нажмите зелёный треугольник рядом с методом main -> Run 'Main.main()'.
  5. Вводите команды в окне Run внизу.

  Если русские буквы в консоли отображаются как "????", откройте
  Help -> Edit Custom VM Options, добавьте строки
      -Dfile.encoding=UTF-8
      -Dstdout.encoding=UTF-8
  и перезапустите IDE.

МОДЕЛЬ ДАННЫХ
-------------
Класс Patient содержит три поля:
  - name        - имя пациента (String);
  - birthYear   - год рождения (int);
  - cardNumber  - номер медицинской карты (String).

МЕНЮ ПРИЛОЖЕНИЯ
---------------
  1. Добавить пациента вручную
  2. Загрузить пациентов из файла
  3. Показать всех пациентов
  4. Фильтр: пациенты, рождённые после указанного года   (filter)
  5. Имена и возраст                                      (map)
  6. Сортировка по году рождения                          (sorted)
  0. Выход

ПРАВИЛА ВАЛИДАЦИИ
-----------------
  - Имя: от 2 до 50 символов; допустимы буквы, пробел, дефис, апостроф.
  - Год рождения: целое число от 1900 до текущего года.
  - Номер карты: ровно 6 цифр, уникальный (дубликаты не добавляются).

При ошибке ручного ввода программа сообщает причину и повторяет запрос.
Некорректные строки в файле пропускаются с сообщением, остальные
загружаются.

ФОРМАТ ФАЙЛА С ДАННЫМИ
----------------------
Кодировка UTF-8. Одна строка - один пациент, поля через точку с запятой:

  имя;год_рождения;номер_карты

Пример:

  Иванов Иван;1985;100001
  Петрова Анна;1992;100002

В файле data/patients.txt две последние строки содержат намеренные ошибки,
чтобы продемонстрировать работу валидации.

ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ
-----------------------
  - Stream API: filter(), map(), sorted(), anyMatch(), toList(), forEach();
  - коллекция List (ArrayList);
  - try-with-resources для чтения файла (BufferedReader);
  - обработка исключений: NumberFormatException, IOException,
    InvalidPathException, ValidationException, NoSuchElementException;
  - принципы ООП: инкапсуляция, разделение ответственности по классам.

СЦЕНАРИЙ ПРОВЕРКИ
-----------------
  1. Ввести "abc" в меню -> "Ошибка: необходимо ввести число."
  2. Пункт 2, путь data/patients.txt -> добавлено 5 пациентов,
     сообщения о пропуске строк 6 и 7.
  3. Пункт 2, путь net.txt -> сообщение об ошибке чтения файла.
  4. Пункт 2 повторно с тем же файлом -> добавлено новых: 0.
  5. Пункт 1, год 3000 -> ошибка и повторный запрос.
  6. Пункт 4, год 1990 -> пациенты 1999 и 2005 года рождения.
  7. Пункт 5 -> имена заглавными буквами и возраст.
  8. Пункт 6 -> список по возрастанию года рождения.
  9. Пункт 0 -> программа завершается.
